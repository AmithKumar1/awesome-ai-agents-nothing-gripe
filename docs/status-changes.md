# Status Changes

The agent ecosystem moves fast — products get acquired, deprecated, or wound down. This log tracks entries in the [main list](../README.md) whose status isn't plain "active". Last updated **2026-09-29**.

## Deprecated / archived

- **OpenAI Operator** (deprecated) — standalone browser-automation product launched Jan 2025; merged into [ChatGPT Agent](../README.md#computer-use--gui-agents) on July 17, 2025. Standalone UI shut down.
- **OpenAI Swarm** (archived) — lightweight educational multi-agent handoff pattern; archived reference implementation, superseded by the [OpenAI Agents SDK](../README.md#agent-frameworks--sdks).
- **AutoGen** (legacy) — Microsoft's conversational multi-agent framework; superseded by the converged [Microsoft Agent Framework](../README.md#agent-frameworks--sdks) and continued by the community as [AG2](../README.md#agent-frameworks--sdks).

## Sunsetting / maintenance mode

- **Flowise** (sunsetting) — visual LangChain/LlamaIndex agent builder; repository archived. Do not build on it.
- **Helicone** (maintenance) — proxy-based LLM observability; in maintenance mode since March 3, 2026 (founding team joined Mintlify). Avoid for greenfield.
- **Zep Community Edition** (deprecated) — managed Zep continues on the Graphiti engine; self-hosted CE is deprecated.

## Acquisitions

- **Langfuse** → ClickHouse (Jan 2026). Open-source tracing/evals product continues.
- **Lakera Guard** → Check Point (Sept 2025). Buy via Check Point.
- **Robust Intelligence** → Cisco. AI firewall + red teaming.
- **Protect AI** → Palo Alto Networks (reported). Model scanning + ML supply-chain security.

## Governance moves

- **MCP** donated to the Linux Foundation (Agentic AI Foundation), Dec 2025.
- **IBM ACP** merged into **A2A** (Aug 2025). (Unrelated to Zed's Agent Client Protocol, which shares the acronym.)
- **AGENTS.md** convention under Agentic AI Foundation governance.
